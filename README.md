# Calculadora React

Calculadora web construida con React y Vite. Incluye operaciones básicas, exponentes, raíz cuadrada y factorial.

## Desarrollo

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3035`.

## Operaciones

- Suma, resta, multiplicación y división
- Exponente
- Raíz cuadrada
- Factorial de enteros no negativos hasta 170

También se puede operar usando el teclado. `Esc` limpia la calculadora y `Enter` calcula el resultado.

## Producción

```bash
npm run build
npm run preview
```
